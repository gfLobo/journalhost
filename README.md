Journalhost é um blog pessoal minimalista, responsivo e acessível. Este tema foi desenvolvido e criado com base no [Astropaper](https://astro.build/themes/details/astropaper/).

Leia [as publicações do blog](https://journalhost.vercel.app/posts/)

## 🔥 Recursos

- [x] Markdown com segurança de tipos
- [x] Desempenho extremamente rápido
- [x] Acessível (Teclado/VoiceOver)
- [x] Responsivo (de dispositivos móveis a desktops)
- [x] Otimizado para SEO
- [x] Modo claro e escuro
- [x] Busca estática ([Pagefind](https://pagefind.app/))
- [x] Publicações em rascunho e paginação
- [x] Sitemap e feed RSS
- [x] Suporte a MDX
- [x] Índice de conteúdo recolhível
- [x] Segue as melhores práticas
- [x] Altamente personalizável
- [x] Geração dinâmica de imagens OG para publicações do blog ([Publicação do Blog](https://astro-paper.pages.dev/posts/dynamic-og-image-generation-in-astropaper-blog-posts/))
- [x] Pronto para i18n (internacionalização)

## 💻 Stack Tecnológica

**Framework Principal** - [Astro](https://astro.build/)  
**Verificação de Tipos** - [TypeScript](https://www.typescriptlang.org/)  
**Estilização** - [TailwindCSS](https://tailwindcss.com/)  
**UI/UX** - [Arquivo de Design do Figma](https://www.figma.com/community/file/1356898632249991861)  
**Busca Estática** - [Pagefind](https://pagefind.app/)  
**Ícones** - [Tablers](https://tabler-icons.io/)  
**Formatação de Código** - [Prettier](https://prettier.io/)  
**Deploy** - [Cloudflare Pages](https://pages.cloudflare.com/)  
**Linting** - [ESLint](https://eslint.org)  
**Imagens OG Dinâmicas** - [Satori](https://github.com/vercel/satori) + [Sharp](https://sharp.pixelplumbing.com/) + [Astro Fonts](https://docs.astro.build/en/guides/fonts/)
